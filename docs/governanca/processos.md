# ⚙️ Processos de Governança CROM

Regras de coordenação, votação e aceitação de novos módulos no Portal.

### Ciclo de Módulos
1. **Proposta:** Criação de um rascunho de ideia na Wiki.
2. **Aprovação:** Consenso entre os administradores das páginas.
3. **Deploy:** Ativação dinâmica via `ModuleLoader` no SQLite.
